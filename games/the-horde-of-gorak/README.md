- 게임 제목·제작진·브랜드 로고는 원문을 유지합니다. JSON 해석 오류 등 일부 진단 문구는 영어로 남아 있습니다.

## 설치·제거

1. 게임을 종료하고 ZIP을 새 폴더에 모두 풉니다.
2. `Install.cmd`를 실행하여 `THOG.exe`가 있는 게임 폴더를 선택합니다.
3. 설치 완료 후 Steam에서 평소처럼 실행합니다.
4. 제거할 때는 게임을 종료한 뒤 `Remove.cmd`에서 같은 폴더를 선택합니다.

원본 백업은 설치 완료 메시지에 나온 경로에 보관됩니다. 설치가 중단되면 같은 버전의 `Install.cmd`를 다시 실행하여 복구하며, 백업은 임의로 삭제하지 마세요. 지원하지 않는 빌드에는 강제로 적용하지 않습니다.
