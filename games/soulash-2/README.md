## 설치·제거

1. 게임을 종료하고 ZIP을 새 폴더에 모두 풉니다.
2. `Install.cmd`를 실행하여 `Soulash 2.exe`가 있는 게임 폴더를 선택합니다.
3. 설치 완료 후 Steam에서 게임을 실행하고 English 언어를 사용합니다.
4. 제거할 때는 게임을 종료한 뒤 `Remove.cmd`에서 같은 폴더를 선택합니다.

설치·제거가 중단되면 같은 버전의 설치기를 다시 실행하여 복구합니다. 완료 전에는 `%LOCALAPPDATA%\Soulash2KoreanPatch\working_private`의 복구 기록을 삭제하지 마세요. 지원하지 않는 빌드에는 강제로 적용하지 않습니다.
